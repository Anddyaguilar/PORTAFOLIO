# Portafolio — Anddy Aguilar

Portafolio profesional de Anddy Aguilar, Ingeniero en Sistemas y desarrollador Full Stack junior.

Sitio estático, sin frameworks, separado en HTML, CSS y JavaScript.

## Estructura

```
.
├── index.html       → contenido y estructura de la página
├── css/
│   └── style.css     → todos los estilos
├── js/
│   └── main.js       → menú móvil, sección activa, tema claro/oscuro, animaciones
└── README.md
```

## Ver en local

Abre `index.html` directamente en el navegador, o sirve la carpeta con cualquier servidor estático:

```bash
npx serve .
```

## Publicar en GitHub Pages

1. Sube estos archivos a la rama `main` de tu repositorio `PORTAFOLIO`.
2. En GitHub: **Settings → Pages → Branch: main → Save**.
3. En unos minutos el sitio queda disponible en `https://anddyaguilar.github.io/PORTAFOLIO/`.
